# Appearance

Open **Appearance** in the Web UI navigation, or choose **Appearance** within **Settings**. Select a theme card to apply it immediately. Appearance is saved in this browser on this device; it does not change the server configuration and does not require **Save**.

The bundled themes are Minimal, autobrr, Kanagawa Dragon, Kanagawa Wave, The Kyle, Napster, Nightwalker, and Swizzin. Minimal is the default. Choose **Use system setting** to follow the device's light or dark preference, or select **Light** or **Dark** explicitly.

Kanagawa Dragon and Kanagawa Wave also offer blueish, pink, green, purple, grayish, and orange accents. Each theme keeps its own accent selection. Napster is light only; selecting it keeps your requested color mode for the next theme.

The selection takes effect before the sign-in screen is painted and is shared with other open tabs in the same browser. If browser storage is disabled or cleared, the current page can still display the chosen theme, but a later visit returns to the default.

To discard the saved choice, choose Minimal and **Use system setting**. Browser data removal also resets the appearance preference.
